## Почему файлов нет в списке вверху страницы

Список вверху (`LICENSE`, `README.md`) — это сам репозиторий, то есть тексты. Пакеты весят десятки мегабайт и у каждой версии свои, поэтому GitHub хранит их отдельно — как вложения к письму — на странице выпуска ([версия 0.26.9](https://github.com/1s83gnsh/shpura-releases/releases/tag/v0.26.9), блок «Assets» внизу). Ссылки выше ведут прямо на эти вложения: нажали — и браузер скачивает файл. Все версии — на странице [Releases](https://github.com/1s83gnsh/shpura-releases/releases).

## Можно ли доверять файлам

Каждый выпуск подписан ключом издателя (Ed25519): сайт ставит пакет, только если подпись верна, а в подписанной описи `shpura-release.json` записан SHA-256 каждого файла. Подменить пакет, даже получив доступ к GitHub, нельзя. Перед установкой сайт сам снимает копию базы и при сбое возвращает прежнюю версию; товары, заказы, покупатели, настройки и фото обновление не меняет.
