# shpura-releases

**Файлы последнего выпуска — [здесь](https://github.com/1s83gnsh/shpura-releases/releases/latest)**: открыть страницу и пролистать вниз до блока «Assets». Все выпуски — [Releases](https://github.com/1s83gnsh/shpura-releases/releases). В списке файлов этой страницы пакетов нет: GitHub хранит их при выпуске, а не в репозитории.

Здесь лежат подписанные выпуски SHPURA для обновления сайтов. Исходный код разработки в этом репозитории не ведётся: он собирается в готовые пакеты, а пакеты публикуются на странице выпусков.

## Какой файл брать

| Задача | Файл |
|---|---|
| Новая установка мастером | `SHPURA-production-<версия>.zip` |
| Обновить работающий сайт вручную | `SHPURA-update-<версия на сайте>-to-<новая версия>.zip` — версия на сайте видна в «Система → Обновление» |
| Сайт сам (кнопка «Установить») | ничего скачивать не нужно |

## Что в выпуске

| Файл | Что это |
|---|---|
| `SHPURA-production-<версия>.zip` | полный пакет для новой установки мастером |
| `SHPURA-update-<с версии>-to-<версия>.zip` | пакет обновления с указанной версии |
| `shpura-release.json` | опись выпуска: версия, заметки, размеры и SHA-256 всех файлов |
| `shpura-release.json.sig` | подпись описи (Ed25519) |

## Как обновляется сайт

Установленный SHPURA раз в сутки и по кнопке «Проверить» читает `shpura-release.json` и подпись последнего выпуска. Если выпуск новее установленного и подписан ключом издателя, сайт сообщает об этом в «Система → Обновление» и ставит его одной кнопкой «Установить». Можно вручную: загрузить ZIP обновления файлом или указать ссылку на страницу выпуска.

Сайт ставит только то, что подписано. Открытый ключ издателя встроен в программу, закрытый хранится только у издателя. Подделать пакет, даже получив доступ к GitHub, нельзя: подпись покрывает опись, а в описи записан хеш каждого файла.

Перед установкой сайт сам снимает копию базы, а при сбое возвращает прежнюю версию. Данные магазина (товары, заказы, покупатели, настройки, ключи, фото) обновление не меняет.
