## Что нового в 0.23.4

- **Обновление кнопкой больше не спотыкается о картинки с кириллицей в имени.** На демо установка 0.23.3 отказала словами
  «нарушена целостность текущего релиза»: в выпуске есть картинка раздела « по номерам_160_160.jpg» (пробел в начале,
  кириллица), а распаковщик панели хостинга такие имена искажает — файл с точным именем на сайте «пропал». Установщик
  прощает пропавший файл, если пакет везёт его с собой, поэтому теперь каждый пакет обновления всегда везёт три файла с
  хрупкими именами (две картинки разделов и один текстовый файл библиотеки) — даже неизменными; установщик кладёт их на
  место с правильным именем. Работает и на уже стоящих сайтах: прощение пропавших файлов есть в установщике с 0.22.12.
- **Отказ скачивания из-за отличий файлов — словами.** Вместо «Нарушена целостность текущего релиза: …» экран говорит,
  сколько файлов отличается или не хватает, и куда смотреть: «Другие способы» → «Файлы сайта».
- Проверки: `scripts/test-package-update.py` (хрупкие имена едут в пакете с точным именем и хешем; изменённая хрупкая
  картинка — по-прежнему отказ «данные магазина»), `update_download_job_run` (С.12, слом доказан); воспроизведение на
  песочнице: сайт 0.23.1 без файла « по номерам_160_160.jpg» — пакет 0.23.3 отказывает, пакет 0.23.4 ставится и
  возвращает файл.

## Почему файлов нет в списке вверху страницы

Список вверху (`LICENSE`, `README.md`) — это сам репозиторий, то есть тексты. Пакеты весят десятки мегабайт и у каждой версии свои, поэтому GitHub хранит их отдельно — как вложения к письму — на странице выпуска ([версия 0.23.4](https://github.com/1s83gnsh/shpura-releases/releases/tag/v0.23.4), блок «Assets» внизу). Ссылки выше ведут прямо на эти вложения: нажали — и браузер скачивает файл. Все версии — на странице [Releases](https://github.com/1s83gnsh/shpura-releases/releases).

## Можно ли доверять файлам

Каждый выпуск подписан ключом издателя (Ed25519): сайт ставит пакет, только если подпись верна, а в подписанной описи `shpura-release.json` записан SHA-256 каждого файла. Подменить пакет, даже получив доступ к GitHub, нельзя. Перед установкой сайт сам снимает копию базы и при сбое возвращает прежнюю версию; товары, заказы, покупатели, настройки и фото обновление не меняет.
